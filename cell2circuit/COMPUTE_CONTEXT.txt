COMPUTE CONTEXT -- Cell2Circuit AAAI-27 Experiments
====================================================

Data sizes
----------
- MICrONS L2/3: ~505 neurons, ~5500 directed edges in the full graph.
  200 subsets at N=100 (~220 edges each) = ~44,000 edges total.
  At N=500: ~5,500 edges per subset, 200 subsets = ~1.1M edge variables.
  Adjacency storage: N=100 -> 40KB per subset, N=500 -> 1MB per subset.
  Full dataset (all scales): ~2GB including features and positions.

- FlyWire whole-brain: 139,255 neurons, 2,700,513 edges.
  At N=500: ~250 edges per subset (density ~0.001).
  80 subsets x 500^2 = ~20M edge variables, ~80MB.

CPU-heavy experiments
---------------------
- Persistent homology (Experiment 2): pyflagser on N=100 graphs
  ~30 min per pipeline config, ~2.5 CPU-hours total for flag complex PH.
  PRH (persistent reachability homology): ~1 CPU-hour additional.
  Walk-length filtration (stretch goal): ~2 CPU-hours.

- Degree prediction (all experiments): sklearn RF/Ridge/KNN fitting.
  ~1-2 CPU-hours total across all scales.

- Motif census (all experiments): networkx triads_by_type on N=100..500.
  N=100: ~1s per graph. N=500: ~30s per graph.
  At N=500, 50 test x 5 configs = 250 motif computations -> ~2 CPU-hours.

- Configuration model sampling: networkx directed_configuration_model.
  Fast (< 1s per graph at N=500).

Memory requirements
-------------------
- N=100 graphs: ~40KB per adjacency, trivial.
- N=500 graphs: ~1MB per adjacency. Sinkhorn on 500x500 matrix: ~2MB. Trivial.
- N=500 DiGress/SparseDiff training: O(500^2) = 250K edge variables per graph.
  With batch_size=8: ~2M edge variables. Fits in 16GB GPU RAM.
  SparseDiff needed for N>=300 if DiGress OOMs (O(N^2) attention).
- PH computation: flag complex of 100-node graph at density 0.022 has O(10^4)
  simplices. Memory: ~100MB. At N=500, density 0.001: similar or smaller.
- Full 505-cell graph evaluation: adjacency is 505x505 = ~1MB. Manageable.

Runtime notes
-------------
- All scripts designed for Jupyter notebook environment (no Modal, no SLURM).
- Each script is self-contained with fallback to synthetic data if MICrONS/
  FlyWire loaders are unavailable.
- Wall-time caps built into PH computation (60 min) to prevent runaway.
- Experiment 2 (PH) is CPU-only and can run overnight on a laptop.
- Experiments 3-5 need GPU but can run on a single consumer GPU (RTX 3090/4090)
  with reduced batch sizes if needed.
