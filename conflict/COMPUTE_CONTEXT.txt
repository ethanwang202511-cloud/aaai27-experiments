Per-Experiment Compute Breakdown
---------------------------------

Experiment 1 -- SAE Feature-Circuit Selectivity (run_sae_selectivity.py)
  Model:    GPT-2 small
  Device:   Mac MPS (M-series)
  Time:     6-10 hours
  Notes:    20-step IG is the bottleneck. 500 null samples x 2 null types x
            2 interventions (zero ablation + causal patching) + raw-dim baseline.
            Preliminary run completed in ~35 min for patching-only at 5-step IG;
            20-step IG + zero ablation roughly triples wall time.

Experiment 2 -- Cross-Model LN Saturation (run_ln_saturation_cross_model.py)
  Gemma-2-2B:   2-4 hours Mac MPS  (26 MLP components x 200 prompts x 2 ablation types)
  Llama-3.1-8B: 2-4 H100-hours     (32 MLP components; model too large for Mac MPS unless 64GB)
  Total:        4-8 hours

Experiment 3 -- Higher-G GQA (run_gqa_higher_g.py)
  Model:    Llama-3.1-8B (G=4) or Mistral-7B
  Device:   H100 (model is 16GB)
  Time:     3-5 H100-hours
            DLA attribution (~1h) + per-head audit n=500 (~1h) + KV-group audit n=500 (~1h) + overhead

Experiment 4 -- Held-Out Split Expanded (run_heldout_split.py)
  GPT-2 cells (4 cells):      ~4h Mac MPS each, ~16h total
  Qwen/Gemma cells (3 cells): ~2-3h Mac MPS each, ~8h total
  Llama cells (3 cells):      ~3-4 H100-hours each, ~12 H100-hours total
  Total:                       ~24h Mac + ~12 H100-hours

Experiment 5 -- Optimal Ablation (run_optimal_ablation.py)
  Phase 1 (learning OA vectors):
    GPT-2:      ~2h Mac    (156 components x up to 10k grad steps each)
    Gemma-2:    ~4h Mac    (234 components)
    Llama-3.1:  ~10 H100-h (1056 components)
  Phase 2 (audit under OA):
    GPT-2:      ~3h Mac    (n=500 null x 4 ablation types)
    Gemma-2:    ~2h Mac
    Llama-3.1:  ~4 H100-h
  Total:        ~11h Mac + ~14 H100-hours

Modal-Stripped Consolidation (run_modal_stripped.py)

  Time varies by model. GPT-2 cells: ~1-2h each on Mac.

Hardware Notes
--------------
  - Mac MPS: Apple M-series GPU. GPT-2 and Gemma-2 fit comfortably.
    Autograd backward pass can be flaky on MPS for some ops; scripts
    include CPU fallback for IG/gradient computations.
  - H100 80GB: Required for Llama-3.1-8B and Mistral-7B at bfloat16.
    All scripts auto-detect CUDA and use it when available.
  - Memory management: Scripts include explicit cache clearing between
    batches (torch.cuda.empty_cache() / torch.mps.empty_cache()).
  - No multi-GPU parallelism needed; all models fit on single GPU.
