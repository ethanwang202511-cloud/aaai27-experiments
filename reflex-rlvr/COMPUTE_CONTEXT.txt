----------------------------------------------------------------------
Experiment Breakdown
----------------------------------------------------------------------

Experiment 1: Multi-Seed Consolidation (run_multiseed.py)
  Cost:     ~$27
  Hardware: 4x H100 (vLLM inference)
  Wall:     ~3-4 hours sequential, ~1 hour with parallelism
  Details:
    Phase 1a: 7 models x 3 seeds x consistent_corruption   ~$8.40
    Phase 1b: 7 models x 3 seeds x verdict                 ~$11.55
    Phase 1c: Qwen2.5-72B x 3 seeds x consistent_corr.     ~$7.23
  Models: 11 total (Qwen2.5 1.5B/7B/72B base+Instruct,
          R1-Distill-Qwen 1.5B/7B, R1-Distill-Llama-8B,
          Llama-3.1-8B, Mistral-7B-v0.3, Gemma-2-9B)
  Seeds:  1337, 37, 31415, 271828

Experiment 2: STaR Self-Teacher Loop (run_star_loop.py)
  Cost:     ~$220 (main) + ~$220 (verdict-only ablation) = ~$440
  Hardware: 4x H100 (generation + LoRA training)
  Wall:     ~3-4 days total
  Details per iteration (~$73):
    Generation (600 problems x 32 chains):              ~$35
    Verdict filtering (600 x 32 x forward pass):        ~$5
    LoRA fine-tune (rank-32, effective batch 256):       ~$20-30
    Evaluation (pass@1, pass@32, MATH-500):             ~$3
  Model:    Qwen2.5-7B base
  LoRA:     rank=32, alpha=64, all linear layers, lr=1e-5
  KL:       0.002 against frozen base
  Ablation: verdict-only vs SymPy-only filtering

Experiment 3: Frontier API Probe (run_frontier_probe.py)
  Cost:     ~$3-5 (API costs only, no GPU)
  Hardware: None (API calls)
  Wall:     ~30 minutes (rate-limited)
  Details:
    GPT-4o (logprobs approach):                         ~$0.50
    Claude Sonnet (sampling approach, N=20):             ~$2.00
  Data:     51 AIME problems x 2 conditions

Experiment 4: Step-Level Verification (run_step_level.py)
  Cost:     ~$17
  Hardware: 4x H100
  Wall:     ~2-3 hours
  Details:
    Phase 4a: per-token surprise, 3 models x 51 problems: ~$2
    Phase 4b: verdict-at-step, 3 models x 51 x ~5 steps:  ~$10
    Phase 4c: PRM comparison (if model available):         ~$5
  Models:   Qwen2.5-7B-Instruct, Qwen2.5-1.5B, Llama-3.1-8B

Experiment 5: Scaling Law Sweep (run_scaling_sweep.py)
  Cost:     ~$24 (+$8 optional Llama-3.1-70B cross-family)
  Hardware: 4x H100 (up to 8x for 72B)
  Wall:     ~4-6 hours
  Details:
    Phase 5a: 6 new models x 2 probes:                    ~$12
    Phase 5b: Curve fitting (local compute):               $0
    Phase 5c: Generation gap (6 models x pass@32):         ~$12
    Phase 5d: Extrapolation (local compute):               $0
  New models: Qwen2.5-3B/14B/32B (base + Instruct)
  Existing:   Qwen2.5-1.5B/7B/72B (from prior runs)
